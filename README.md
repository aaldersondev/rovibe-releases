# RoVibe

Agents (Claude Code, Codex) that build Roblox games in Roblox Studio, side by side, from one Windows app.

**[Download the latest version](https://github.com/aaldersondev/rovibe-releases/releases/latest)**: Windows 10/11, 64-bit. Once installed, RoVibe updates itself from this repository.

This repository holds RoVibe's installers and the file installed copies read to find updates. RoVibe's own code is proprietary; versions up to 0.14.4 were published under the MIT license.

RoVibe's sync server is a fork of [Rojo](https://github.com/rojo-rbx/rojo) and stays under the Mozilla Public License 2.0: its source is in [aaldersondev/rovibe-sync](https://github.com/aaldersondev/rovibe-sync).
